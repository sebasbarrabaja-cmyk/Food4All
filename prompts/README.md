# Prompts del proyecto

Registro de todos los prompts usados para desarrollar FOOD4ALL. Se consultan, se añaden y se pulen con IA desde el panel de administración (sección **Prompts**).

- Un fichero `.md` por prompt, con nombre `AAAA-MM-DD-titulo.md`, para que se ordenen por fecha.
- Cabecera entre líneas `---` con `titulo`, `fecha`, `autor`, `herramienta`, `tipo` y `origen`.
- Los prompts se guardan tal cual se enviaron, con sus erratas: es un registro, no un documento pulido. Las versiones mejoradas se guardan aparte con el tipo "Versión pulida".
- Si añadís uno a mano, seguid el mismo formato y subidlo con el resto de cambios.
